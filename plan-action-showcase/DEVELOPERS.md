# 👨‍💻 Equipe de Desenvolvimento - Plan-Action

## 📌 Sobre o Projeto

**Plan-Action** é um projeto educacional desenvolvido por **4 alunos** da **Escola SESI Senai Blumenau** como trabalho final de curso, demonstrando as habilidades adquiridas em:

- Desenvolvimento Web (Frontend & Backend)
- Gestão de Projetos
- User Experience Design
- Trabalho em Equipe
- Inovação Tecnológica

## 🎯 Objetivos do Projeto

O Plan-Action foi criado com os seguintes objetivos:

1. **Educacional**: Aplicar conhecimentos de desenvolvimento em um projeto real
2. **Prático**: Resolver um problema real da Escola SESI
3. **Inovador**: Criar uma solução moderna e intuitiva
4. **Sustentável**: Desenvolver um produto gratuito para uso contínuo
5. **Colaborativo**: Demonstrar trabalho em equipe efetivo
